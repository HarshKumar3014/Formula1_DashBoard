# Pit Wall F1 API

FastAPI backend for the [Pit Wall](https://github.com/HarshKumar3014/Formula1_DashBoard) F1 dashboard:
Fast-F1 telemetry, Jolpica standings/schedule, RSS news, session replay bundles and live timing over
WebSocket.

Endpoints: `/api/health`, `/api/standings`, `/api/drivers`, `/api/news`, `/api/schedule`,
`/api/circuits`, `/api/records`, `/api/telemetry/...`, `/api/replay`, `/api/live/status`, `/ws/live`.
